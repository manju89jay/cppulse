# Official SARIF test reference

`sarif-schema-2.1.0.json` is the unchanged OASIS SARIF 2.1.0 + errata01 schema. Its original URL, actual retrieval time, byte count and SHA-256 are retained unchanged in `provenance.json`.

The upstream terms supplied alongside that reference are retained byte-for-byte in `upstream-LICENSE.md`. These reference files are not relabeled as MIT or Apache material. The terms text retains its original links to OASIS policies.

Tests use this local reference for offline schema validation. These files reside outside the Python package and are not included in the core wheel.
