# Versioned local contracts

Status: S2 implementation, not a published release. New schemas and validators
live in python/cppulse/contracts and load resources locally without fetching
schema URLs. The existing flat analyzer/Git/predictor/report pipeline retains
its explicit prototype-v1 contracts while consumers migrate.

## Supported interpretations

| Input | Reader | Meaning |
|---|---|---|
| Checkpoint risk v1 | read_risk_scores(document) | Frozen known numeric/XGBoost-shaped format; original observed values retained, full-scope/evaluation claims unverified |
| Unreleased extended v1-shaped output | read_risk_scores(document, allow_prototype_v1=True) | Explicit opt-in; allows heuristic/null/partial output without pretending it was an original stable v1 contract |
| Risk v2 | read_risk_scores(document) | Validated ranking score, method, active inputs, evaluation availability and separate health availability |
| Other existing native documents | read_prototype_document(kind, document) | Explicit prototype contract selection; no provenance manufactured |

V2 does not label an uncalibrated ranking as bug probability. Original observed
health can be retained without being promoted to verified full-scope health.
An unrepresentable legacy export fails clearly rather than fabricating numeric
scores or an XGBoost method name.

## Contract families

Source, compiler context, artifact, run manifest, recipe, execution receipt,
evidence, policy, assessment, baseline, observations, analysis metrics, rule
registry and risk output have draft-07 schemas plus semantic validation. Schema
presence does not implement a collector, adapter, evaluator or user workflow.

Examples and negative cases are in tests/test_contracts_v2.py and
tests/test_compatibility_v2.py. Validation covers duplicate IDs, dangling
references, cycles, invalid weights, typed outcomes, canonical paths, finite
JSON, identity digests and supported versions. Public calls are
load_schema(kind, version=None), validate(kind, document, version=None) and
validate_bundle(documents).

Source digest: SHA-256 of canonical UTF-8 JSON containing kind, sorted file
manifest and inventory_complete. Compiler-context digest excludes the context
ID, digest, version and human-readable limitations, preserving actual argv
order and semantic input values. Hashes establish identity/integrity, not
producer authentication. Inventory completeness is a caller assertion about a
finite declared input list, not automatic discovery of all possible inputs.

Execution outcomes and assessment controls are separate. A completed collection
may contain observed failed checks; operationally incomplete stages cannot be
misrepresented as a completed collection. The external gate vocabulary is
passed, failed and insufficient_evidence. The pure evaluation engine and exact
gate precedence remain S5 implementation.

## Source-tree checks

For direct source-tree scripts, use PYTHONPATH=python; root pytest includes the
namespace through pytest.ini. Installed commands use wheel resources and native
prefix metadata without checkout discovery. The accepted S3 artifact was tested
with the original checkout path temporarily absent; see review/autonomous/S3-REVIEW.md.

The S1 corrected source-universe denominator has the explicit scorer identity
weighted-findings-per-attempted-file-v2; its category weights are unchanged.
The previous merged-row denominator and the proposed KLOC method are not
silently treated as the same comparable score.
